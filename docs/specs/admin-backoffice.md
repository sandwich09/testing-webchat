# หน้าตั้งค่า

> สถานะ: สร้างแล้ว · อัปเดตล่าสุด: 2026-11-19

## เป้าหมาย

เจ้าของร้านเชื่อม LINE OA, ควบคุม AI, ดูแลคลังความรู้ และเห็นค่าใช้จ่าย ได้จากหน้าเดียว

หน้าตั้งค่าเป็นหน้าเดียวเรียงเป็นส่วน คั่นด้วยเส้นบาง ตามลำดับ: AI ตอบแทน, ขอบเขตหัวข้อ, Guardrails, LINE Official Account, คลังความรู้, ข้อความสำเร็จรูป, ค่าใช้จ่าย AI และสถานะระบบ

## ส่วน AI ตอบแทน

| รายการ | พฤติกรรม |
| --- | --- |
| เปิดใช้ AI ทั้งระบบ | Kill switch ปิดแล้ว AI หยุดตอบลูกค้าทุกคนทันที มีผลกับข้อความที่กำลังประมวลผลด้วย |
| โมเดล | เลือกจาก Claude Opus 5.5 (ค่าเริ่มต้น), Claude Sonnet 5.5, Claude Haiku 5.5 มีผลกับข้อความถัดไป |
| งบต่อวัน | เป็นดอลลาร์ ถึงเพดานแล้ว AI หยุดจนถึงเที่ยงคืนตามเวลาไทย และแสดงยอดที่ใช้ไปวันนี้ |
| คำลงท้าย | "ค่ะ" (ค่าเริ่มต้น) หรือ "ครับ" |
| คำแนะนำสำหรับ AI | ข้อความที่ร้านเขียนเอง เช่น น้ำเสียงและข้อห้าม |

รายละเอียดของ AI อยู่ใน [ai-reply](ai-reply.md)

## ส่วนขอบเขตหัวข้อ

| รายการ | พฤติกรรม |
| --- | --- |
| จำกัดหัวข้อที่ AI คุยได้ | สวิตช์เปิดปิดขอบเขตหัวข้อ เปิดได้เมื่อมีหัวข้ออย่างน้อยหนึ่งหัวข้อ |
| หัวข้อที่คุยได้ | หนึ่งบรรทัดต่อหนึ่งหัวข้อ ไม่เกิน `GUARD_MAX_TOPICS` หัวข้อ พร้อมตัวนับ |
| ข้อความเมื่อถูกกัน | ข้อความที่ AI ส่งให้ลูกค้าเมื่อข้อความอยู่นอกหัวข้อ |
| ทดลอง | พิมพ์ข้อความแล้วกด "ทดสอบ" เห็นผลว่าผ่านหรือถูกกันพร้อมค่าใช้จ่ายโดยประมาณ กดไม่ได้เมื่อ AI ถูกปิดทั้งระบบ |
| วันนี้กันไปกี่ข้อความ | ตัวนับของวันนี้ตามเวลาไทย |

ทุก control แก้ได้แม้ kill switch ปิด รายละเอียดอยู่ใน [topic-guard](topic-guard.md)

## ส่วน Guardrails

แสดงตัวเลขของวันนี้ตามเวลาไทยแบบอ่านอย่างเดียว หนึ่งแถวต่อสิ่งที่นับ จัดตามชั้นของ guardrail: สวิตช์ AI ทั้งระบบ, ข้อความที่ขอบเขตหัวข้อกัน, ข้อความที่ไม่ใช่ตัวอักษร, คำตอบที่ไม่ผ่าน schema หรือถูกปฏิเสธ, การไม่มีเครื่องมือของ AI, การส่งต่อแอดมินแยกตามกลุ่มเหตุผล และงบที่เต็ม ทุกตัวเลขมาจากข้อมูลที่ระบบเก็บอยู่แล้ว ความหมายของแต่ละชั้นอยู่ใน [ai-guardrails](../security/ai-guardrails.md)

## ส่วน LINE Official Account

1. แสดงชื่อและ Basic ID ของ OA ที่เชื่อมอยู่ พร้อมสถานะ เวลาที่รับข้อความล่าสุด และสิ่งที่รู้เกี่ยวกับ Channel secret: LINE ยืนยันแล้ว, ยังตรวจกับ LINE ไม่ได้ (ให้กด "ทดสอบการเชื่อมต่อ" ภายหลัง) หรือยังไม่ได้ตรวจเพราะยังไม่มี Channel ID
2. แสดง Webhook URL แบบอ่านอย่างเดียว พร้อมปุ่ม "คัดลอก"
3. กรอก Channel ID, Channel secret และ Channel access token ได้ Channel ID เป็นตัวเลขเท่านั้นไม่เกิน `LINE_CHANNEL_ID_MAX_CHARS` หลัก ไม่ใช่ความลับ จึงแสดงค่าที่บันทึกไว้ในช่องและยังอยู่หลังบันทึก ส่วน Channel secret และ Channel access token ระบบไม่แสดงค่าเดิมกลับ ไม่ว่าในรูปแบบใด
4. เมื่อบันทึก ระบบตรวจกับ LINE ก่อนสองเรื่อง: access token ใช้ได้ และ Channel secret เป็นของ Channel ID นั้น (LINE ออก token อายุสั้นแบบ client credentials ให้เมื่อคู่ถูก ระบบเพิกถอนทันที ไม่เก็บและไม่ log) ถ้าข้อใดไม่ผ่าน ไม่บันทึกและบอกเหตุผล ถ้า LINE ตอบการตรวจ secret ไม่ได้ (429, 5xx, ไม่มีเครือข่าย, timeout) ระบบบันทึกให้ และสถานะแสดงว่ายังตรวจ Channel secret ไม่ได้
5. ปุ่ม "ทดสอบการเชื่อมต่อ" เรียก LINE เพื่อยืนยันว่า access token ยังใช้ได้ และตรวจ Channel secret กับ Channel ID ที่บันทึกไว้ด้วย ผลบอกทั้งสองเรื่อง
6. Credential ที่บันทึกไว้ก่อนมีช่อง Channel ID ยังใช้รับและส่งข้อความได้ตามเดิม สถานะบอกว่ายังไม่ได้ตรวจ Channel secret จนกว่าจะบันทึกใหม่พร้อม Channel ID

ขั้นตอนฝั่ง LINE อยู่ใน [runbooks/line-oa-setup](../runbooks/line-oa-setup.md)

## ส่วนค่าใช้จ่าย AI

ตารางต่อลูกค้าและยอดรวมของเดือน รายละเอียดอยู่ใน [usage-cost](usage-cost.md)

## ส่วนสถานะระบบ

แสดงเพื่อให้รู้ว่าระบบทำงานอยู่ โดยไม่ต้องเปิด log

- เวลาที่รับ webhook ล่าสุด
- ข้อผิดพลาดล่าสุดของ LINE และของ AI พร้อมเวลา
- งบ AI ที่ใช้ไปวันนี้เทียบกับเพดาน
- สถานะการต่อฐานข้อมูล

## กรณีผิดพลาด

| เหตุการณ์ | แอดมินเห็นอะไร |
| --- | --- |
| Token ของ LINE ไม่ถูกต้อง | "Channel access token ไม่ถูกต้อง ตรวจค่าที่คัดลอกมาอีกครั้ง" และค่าที่กรอกยังอยู่ |
| Channel ID กับ Channel secret ไม่ใช่คู่กัน | "Channel ID กับ Channel secret ไม่ตรงกัน ตรวจว่าคัดลอกทั้งสองค่ามาจาก channel เดียวกัน" ไม่บันทึก และค่าที่กรอกยังอยู่ |
| LINE ตรวจ Channel secret ไม่ได้ตอนบันทึก | บันทึกแล้ว และสถานะแสดง "ยังตรวจ Channel secret กับ LINE ไม่ได้ กด "ทดสอบการเชื่อมต่อ" อีกครั้งภายหลัง" |
| Channel ID ไม่ใช่ตัวเลข หรือยาวเกิน | "Channel ID เป็นตัวเลขเท่านั้น ไม่เกิน {max} หลัก" ใต้ช่อง ไม่ส่งถึง server |
| บันทึกไม่สำเร็จเพราะระบบ | "บันทึกไม่สำเร็จ ข้อมูลที่กรอกยังอยู่ ลองอีกครั้ง" |
| ยังไม่ได้ตั้งค่า LINE OA | ส่วน LINE แสดงขั้นตอนเริ่มต้น และหน้าแชทแจ้งให้มาตั้งค่า |

## สิ่งที่ไม่ทำ

- กรอก API key ของ AI ผ่านหน้าเว็บ (อยู่ใน environment variable)
- เปลี่ยนรหัสเข้าใช้ผ่านหน้าเว็บ
- หลาย LINE OA

## วิธีทดสอบ

- Unit: การตรวจค่าที่กรอก (รวมรูปแบบของ Channel ID), การเข้ารหัส credential, การไม่คืนค่าความลับใน response, ผลของการตรวจ Channel secret ทั้งสามแบบ
- Adapter: การตรวจ Channel secret แบบ client credentials กับ stub และการเพิกถอน token
- E2E เส้นที่ 4, 6 และ 9

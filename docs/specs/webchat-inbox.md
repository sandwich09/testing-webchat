# หน้าแชท

> สถานะ: สร้างแล้ว · อัปเดตล่าสุด: 2026-11-18

## เป้าหมาย

แอดมินเห็นว่าใครทักมา เลือกลูกค้า อ่านประวัติ และตอบกลับได้เร็ว โดยรู้เสมอว่าข้อความของตัวเองส่งถึงหรือไม่

โครงหน้าและ design system อยู่ใน [frontend](../architecture/frontend.md)

## รายชื่อลูกค้า

1. แต่ละแถวแสดง: รูปโปรไฟล์ (หรือตัวอักษรแรกของชื่อ), ชื่อ, ข้อความล่าสุดหนึ่งบรรทัด, เวลา และจำนวนยังไม่อ่าน
2. ข้อความล่าสุดบอกผู้ส่งฝั่งร้านด้วยคำนำ "คุณ:" หรือ "AI:" และสื่อแสดงเป็นคำ เช่น "รูปภาพ", "วิดีโอ", "สติกเกอร์"
3. แถวที่ยังไม่อ่านใช้ชื่อตัวหนา
4. แชทที่รอแอดมินแสดงคำว่า "รอแอดมิน" นำหน้าข้อความล่าสุด
5. ลูกค้าที่เลิกติดตามแสดงเป็นสีจางพร้อมคำว่า "เลิกติดตามแล้ว"
6. เรียงตามเวลาข้อความล่าสุด
7. ตัวกรอง: ทั้งหมด, ยังไม่อ่าน, รอแอดมิน พร้อมจำนวน
8. ค้นหาจากชื่อลูกค้า
9. รูปแบบเวลา: วันนี้แสดงเวลา, เมื่อวานแสดง "เมื่อวาน", ภายในสัปดาห์แสดงชื่อวันย่อ, เก่ากว่านั้นแสดงวันที่

## ห้องแชท

1. ส่วนหัว: รูป, ชื่อ, สถานะการติดตาม, สวิตช์ "AI ตอบแทน" และปุ่มเปิดปิดแผงข้อมูลลูกค้า
2. ข้อความของลูกค้าอยู่ซ้าย ของร้านอยู่ขวา ข้อความที่ส่งติดกันจัดเป็นกลุ่ม
3. ข้อความฝั่งร้านระบุผู้ส่งว่า "คุณ" หรือ "AI" ข้างเวลา
4. ตัวคั่นวันที่ และบรรทัดแจ้งเหตุการณ์ เช่น "ลูกค้าส่งรูป AI จึงหยุดรอแอดมิน" บรรทัดเหตุการณ์เป็นข้อความที่บันทึกไว้ จึงอยู่ตามลำดับเวลาที่เกิด ข้อความไทยอยู่ใน [error-catalog](../architecture/error-catalog.md#บรรทัดเหตุการณ์)
5. ข้อความแสดงเป็นข้อความล้วนเสมอ ลิงก์เปิดแท็บใหม่ และข้อความยาวหรือ URL ไม่ล้นฟอง
6. รูปและวิดีโอแสดงภาพตัวอย่าง กดเพื่อดูขนาดเต็ม
7. เปิดแชทแล้วจำนวนยังไม่อ่านถูกล้าง
8. โหลด `MESSAGE_PAGE_LIMIT` ข้อความล่าสุด และโหลดเพิ่มเมื่อเลื่อนขึ้น
9. เลื่อนตามข้อความใหม่เฉพาะเมื่ออยู่ล่างสุด ถ้าเลื่อนขึ้นไปแล้วมีข้อความใหม่ แสดงปุ่ม "ข้อความใหม่"

## ช่องตอบ

1. ช่องพิมพ์ข้อความ, ปุ่มแนบรูปหรือวิดีโอ, ปุ่มข้อความสำเร็จรูป และปุ่ม "ส่ง"
2. Enter ส่ง และ Shift+Enter ขึ้นบรรทัดใหม่
3. ข้อความขึ้นในห้องแชททันทีในสถานะ "กำลังส่ง"
4. กดส่งซ้ำหรือ retry กี่ครั้ง ลูกค้าได้รับข้อความเดียว
5. การแนบไฟล์แสดงความคืบหน้าและยกเลิกได้ ข้อกำหนดของไฟล์อยู่ใน [line-messaging](line-messaging.md)
6. ช่องตอบถูกปิดเมื่อลูกค้าเลิกติดตาม หรือยังไม่ได้ตั้งค่า LINE OA พร้อมบอกเหตุผล
7. เมื่อแอดมินส่งข้อความ AI ตอบแทนของลูกค้าคนนั้นถูกปิด สถานะรอแอดมินถูกล้าง และมีบรรทัดเหตุการณ์ AI กลับมาเมื่อเปิดสวิตช์อีกครั้งเท่านั้น ดู [ai-reply](ai-reply.md#เมื่อแอดมินตอบเอง)
8. ปุ่มข้อความสำเร็จรูปเปิดรายการที่ร้านเตรียมไว้ เลือกแล้วข้อความถูกแทรกลงช่องพิมพ์ให้แก้ก่อนส่ง ไม่ส่งทันที
9. เมื่อแอดมินเริ่มพิมพ์ ระบบขอให้ LINE แสดง loading ในแอปของลูกค้าเป็นเวลา `LINE_LOADING_SECONDS` หน้าเว็บส่งไม่เกินหนึ่งครั้งต่อ `TYPING_PING_INTERVAL_MS` ขณะพิมพ์ และ server จำกัดไม่เกิน `RATE_LIMIT_TYPING` ต่อลูกค้า ถ้าเรียกไม่สำเร็จไม่ถือเป็นความล้มเหลว

## แผงข้อมูลลูกค้า

- รูป ชื่อ และวันที่เพิ่มเพื่อน
- สวิตช์ "AI ตอบแทน" พร้อมคำอธิบายหนึ่งบรรทัด
- รายละเอียด: สถานะ, จำนวนข้อความทั้งหมด, จำนวนครั้งที่ AI ตอบ และเวลาที่ทักล่าสุด
- ไม่แสดง token หรือค่าใช้จ่าย ซึ่งอยู่ในหน้าตั้งค่าเท่านั้น

## สวิตช์ AI ตอบแทนเมื่อ kill switch ปิด

เมื่อ "เปิดใช้ AI ทั้งระบบ" ในหน้าตั้งค่าถูกปิด สวิตช์รายลูกค้าทั้งในส่วนหัวและแผงข้อมูลกดไม่ได้ แสดงเป็นปิด และมีข้อความ "AI ถูกปิดทั้งระบบ เปิดได้ที่ ตั้งค่า › AI ตอบแทน" ค่าเดิมของแต่ละลูกค้ายังถูกจำไว้ และกลับมาเมื่อเปิด kill switch

## กรณีผิดพลาดและกรณีขอบ

| เหตุการณ์ | แอดมินเห็นอะไร |
| --- | --- |
| ยังไม่มีลูกค้าทักมา | หน้าว่างพร้อมคำแนะนำให้ตั้งค่า LINE OA และเพิ่มเพื่อน |
| ส่งไม่สำเร็จ | ข้อความขึ้น "ส่งไม่สำเร็จ" บอกเหตุผล และมีปุ่ม "ส่งอีกครั้ง" |
| ส่งไม่สำเร็จ และผ่าน `LINE_RETRY_KEY_WINDOW_MS` นับจาก push ครั้งแรกแล้ว | ข้อความบอกว่าส่งอีกครั้งไม่ได้แล้วและให้พิมพ์ส่งใหม่ ไม่มีปุ่ม "ส่งอีกครั้ง" เพราะ LINE ลืม retry key แล้ว การส่งซ้ำอาจถึงลูกค้าสองครั้ง ([line-messaging](line-messaging.md#ส่งข้อความ) ข้อ 5) |
| รูปโปรไฟล์โหลดไม่ได้ | ตัวอักษรแรกของชื่อ |
| สื่อขาเข้าดาวน์โหลดไม่ได้ | ป้าย "โหลดรูปไม่สำเร็จ" |
| การเชื่อมต่อกับ server มีปัญหา | แถบแจ้งด้านบน และข้อความที่พิมพ์ค้างไว้ยังอยู่ |
| ส่วนหนึ่งของหน้าพัง | เฉพาะส่วนนั้นแสดงข้อผิดพลาด ส่วนอื่นยังใช้ได้ |

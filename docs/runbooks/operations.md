# การดูแลระบบ

> สถานะ: อนุมัติ · อัปเดตล่าสุด: 2026-11-19

## หยุด AI ทันที

1. เปิดหน้าตั้งค่า ส่วน AI ตอบแทน
2. ปิด "เปิดใช้ AI ทั้งระบบ"

มีผลทันที รวมถึงข้อความที่กำลังประมวลผล ซึ่งจะไม่ถูกส่งออก

ถ้าเข้าหน้าเว็บไม่ได้ ให้ปิดสวิตช์เดียวกันในฐานข้อมูล: เปิด SQL Editor ของ Neon ที่ฐานข้อมูล production แล้วรัน

```sql
UPDATE "Settings" SET "aiEnabled" = false WHERE "id" = 1;
```

ไม่ต้อง deploy ใหม่ ทุกงานของ AI (`GenerateAiReply`, การกด "คุยกับ AI") อ่านค่านี้จากฐานข้อมูลก่อนเรียกโมเดลและอีกครั้งก่อนส่ง จึงหยุดตั้งแต่งานถัดไป ([use-cases GenerateAiReply](../architecture/use-cases.md#generateaireply)) เปิดกลับด้วยสวิตช์ในหน้าตั้งค่า หรือคำสั่งเดียวกันด้วย `true` ([`settings.repository.spec.ts`](../../src/adapters/prisma/settings.repository.spec.ts) ตรวจว่าคำสั่งนี้มีผลกับ `SettingsRepository.get` ทันที)

ห้ามลบ `ANTHROPIC_API_KEY`: ตัวแปรนี้บังคับตอนเริ่มระบบ ([project-setup ข้อ 6.10](../architecture/project-setup.md#610-envexample)) ลบแล้วทุก function เริ่มไม่ได้ webhook, `/api/health` และหน้าแชทจึงหยุดทั้งหมด การเปลี่ยน key เป็นค่าที่ใช้ไม่ได้ก็ไม่แนะนำ: ต้อง deploy ใหม่ และทุกข้อความยังเรียก API ก่อนแล้วขึ้นรอแอดมินด้วยเหตุผล AI ตอบไม่สำเร็จ

## AI ไม่ตอบ

ตรวจตามลำดับ:

1. "เปิดใช้ AI ทั้งระบบ" เปิดอยู่หรือไม่
2. "AI ตอบแทน" ของลูกค้าคนนั้นเปิดอยู่หรือไม่ (ปิดเองเมื่อแอดมินส่งข้อความ และไม่กลับมาเองจนกว่าจะเปิดสวิตช์)
3. งบของวันนี้ถึงเพดานหรือไม่ ดูในส่วนสถานะระบบ
4. ข้อความล่าสุดเป็นรูป วิดีโอ เสียง สติกเกอร์ หรือชนิดอื่นที่ไม่ใช่ตัวอักษรหรือไม่ ซึ่ง AI ไม่ตอบ และแชทขึ้น "รอแอดมิน" แทน
5. ขอบเขตหัวข้อเปิดอยู่หรือไม่ ถ้าเปิด ลูกค้าที่ถามนอกหัวข้อ (รวมเรื่องที่อยู่ในคลังความรู้) ได้ข้อความปฏิเสธแทนคำตอบ ดูบรรทัด "นอกขอบเขตหัวข้อ AI จึงไม่ตอบ" ในแชท และใช้กล่องทดลองในส่วนขอบเขตหัวข้อตรวจหัวข้อ ([topic-guard](../specs/topic-guard.md))
6. ข้อผิดพลาดล่าสุดของ AI ในส่วนสถานะระบบ (การคัดกรองขอบเขตหัวข้อที่ล้มเหลวทำให้แชทขึ้น "รอแอดมิน" ด้วยเหตุผล AI ตอบไม่สำเร็จ) รหัส `ai.link_not_allowed` แปลว่าคำตอบมีลิงก์ที่แอดมินไม่ได้เขียนไว้จึงไม่ถูกส่ง ถ้าลิงก์นั้นถูกต้อง ให้เพิ่มลงในคำแนะนำสำหรับ AI หรือในไฟล์ของคลังความรู้ ([ai-prompt ข้อ 6.1](../specs/ai-prompt.md#61-ลิงก์ในคำตอบ))

## ค่าใช้จ่าย AI ไม่ตรงกับบิล

ระบบบันทึกเฉพาะยอดที่ API รายงาน การเรียกที่ส่งไปแล้วไม่ได้คำตอบ (`ai.no_response`) ถูกบันทึกเป็นแถวที่ยอดเป็นศูนย์ และนับเป็นบรรทัด "ส่งคำขอถึง AI แล้วไม่ได้คำตอบ" ใต้ตารางค่าใช้จ่าย ([usage-cost](../specs/usage-cost.md#การเรียกที่ไม่ได้คำตอบ)) เมื่อเทียบยอดเดือนละครั้ง:

1. เปิด console ของผู้ให้บริการ AI ดูยอดของเดือนที่ต้องการ
2. เทียบกับ "รวมทั้งเดือน" ในหน้าตั้งค่า ส่วนค่าใช้จ่าย AI
3. ถ้า console สูงกว่าเกินราว 10% และบรรทัดการเรียกที่ไม่ได้คำตอบมีจำนวนมาก ส่วนต่างน่าจะมาจากการเรียกเหล่านั้น ให้ลดงบต่อวันลงระหว่างหาสาเหตุของ timeout (ดู `durationMs` ของ `ai.model.called` และ `guard.checked`)
4. ถ้าไม่มีการเรียกที่ไม่ได้คำตอบแต่ยอดยังต่าง ให้ตรวจวันที่ของตารางราคา (`priceTableDate`) กับราคาปัจจุบันของผู้ให้บริการ

## อาการอื่น

อาการที่ไม่อยู่ในหัวข้อด้านบน เช่น ข้อความซ้ำ, สถานะค้าง, ค่าใช้จ่าย AI ไม่ตรง, deploy ล้มที่ migration หรือหน้าเว็บค้าง ดูสาเหตุและวิธีตรวจใน [pitfalls-and-prevention](../guidelines/pitfalls-and-prevention.md) ซึ่งอ้างชื่อ log ของแต่ละกรณี

## หมุน credential

| สิ่งที่หมุน | ขั้นตอน |
| --- | --- |
| Channel access token ของ LINE | ออก token ใหม่ใน LINE Developers Console, บันทึกในหน้าตั้งค่า, กด "ทดสอบการเชื่อมต่อ" แล้วจึงเพิกถอน token เก่า |
| Channel secret ของ LINE | ออกใหม่ใน LINE Developers Console แล้วบันทึกในหน้าตั้งค่าทันทีพร้อม Channel ID (ระบบตรวจว่าเป็นคู่กันก่อนบันทึก) ระหว่างนั้น webhook จะถูกปฏิเสธ |
| API key ของ AI | สร้าง key ใหม่, แก้ `ANTHROPIC_API_KEY` ใน Vercel, deploy ใหม่ แล้วลบ key เก่า |
| รหัสเข้าใช้ | แก้ `ACCESS_CODE` ใน Vercel แล้ว deploy ใหม่ cookie ที่ออกด้วยรหัสเดิมใช้ไม่ได้ทันทีหลัง deploy ทุกคนต้องเข้าระบบใหม่ด้วยรหัสใหม่ ([access-gate](../specs/access-gate.md#พฤติกรรม) ข้อ 6) |
| `SESSION_SECRET` | แก้แล้ว deploy ใหม่ ทุกคนต้องเข้าระบบใหม่ |
| `CREDENTIALS_ENCRYPTION_KEY` | แก้แล้ว credential ของ LINE ที่เก็บไว้จะถอดรหัสไม่ได้ ต้องกรอกใหม่ในหน้าตั้งค่า |

## ลบข้อมูลของลูกค้าหนึ่งคน

ใช้เมื่อลูกค้าขอลบข้อมูล ระบบไม่มีปุ่มในหน้าเว็บ

1. หา Contact จาก id ของ LINE หรือชื่อที่แสดง ในฐานข้อมูล
2. เก็บรายการ URL ของสื่อ (รูป วิดีโอ เสียง และภาพตัวอย่าง) จากข้อความของ Contact นั้น
3. ลบไฟล์สื่อเหล่านั้นจาก Blob store
4. ลบข้อความของ Contact แล้วลบ Contact (โน้ตของแอดมินใน `ContactNote` ถูกลบตามไปเอง)
5. แถว AiUsage ของ Contact นั้นไม่มีเนื้อหาข้อความ และการลบ Contact ตั้ง `contactId` ของแถวเหล่านั้นเป็น null เอง ยอดจึงยังอยู่ในค่าใช้จ่ายรวม
6. บันทึกวันที่และสิ่งที่ลบ โดยไม่บันทึกเนื้อหา

ทำบนสำเนาสำรองไม่ได้ จึงตรวจ id ให้แน่ใจก่อนลบ

## คลังความรู้

- คำตอบของ AI ไม่ตรงกับเอกสาร: เปิดอ่านข้อความที่แปลงแล้วในหน้าตั้งค่า ถ้าแปลงผิดให้ลบแล้วอัปโหลดไฟล์ที่ชัดกว่า
- คลังเต็ม: ลบไฟล์ที่ไม่ใช้ เพดานคือ `KNOWLEDGE_CAPACITY_TOKENS` ([project-setup](../architecture/project-setup.md#101-แกนกลาง))

## ปิดระบบหลังส่งงาน

เมื่อผู้ตรวจตรวจเสร็จ:

1. ปิด "เปิดใช้ AI ทั้งระบบ"
2. เพิกถอน Channel access token ของ LINE และปิด webhook ใน LINE Developers Console
3. ลบหรือจำกัดวงเงินของ API key ของ AI
4. เปลี่ยนรหัสเข้าใช้แล้ว deploy ใหม่ (ทุก cookie เดิมใช้ไม่ได้) หรือหยุดโปรเจกต์บน Vercel
5. ลบข้อมูลในฐานข้อมูลและ Blob store ถ้ามีข้อมูลของคนจริงจากช่วงทดสอบ

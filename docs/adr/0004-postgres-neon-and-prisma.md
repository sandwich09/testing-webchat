# 0004: PostgreSQL บน Neon กับ Prisma 7

> สถานะ: อนุมัติ · วันที่: 2026-11-18

## บริบท

Vercel เป็น serverless เก็บข้อมูลในหน่วยความจำไม่ได้ ต้องมีฐานข้อมูลภายนอกที่มีแผนฟรี และต้องรันใน Docker ได้เหมือนกัน

## การตัดสินใจ

ใช้ PostgreSQL 17 โดย production อยู่บน Neon region สิงคโปร์ ส่วน Docker และ CI ใช้ Postgres ใน container เข้าถึงด้วย Prisma 7.10 กับ `@prisma/adapter-pg` ซึ่งเป็น driver มาตรฐาน ล็อกรุ่นของ Prisma เอง id สร้างในแอป เวลาเป็น UTC ราคาเป็นทศนิยมแม่นยำ และการกันซ้ำใช้การ insert แบบข้ามเมื่อซ้ำ

## ทางเลือกที่พิจารณา

- Drizzle: เบากว่า แต่ยังเป็นรุ่น 0.x และเจ้าของงานคุ้นกับ Prisma มากกว่า
- Driver เฉพาะของ Neon: รันกับ Postgres ใน Docker ไม่ได้
- Redis: เหมาะกับข้อความล่าสุด แต่รายงานค่าใช้จ่ายและการค้นทำได้ยากกว่า

## ผลที่ตามมา

โค้ดเดียวรันได้ทุกสภาพแวดล้อม ข้อเสียคือ Neon แผนฟรีหลับเมื่อไม่มีการใช้ คำขอแรกจึงช้า

## จะทบทวนเมื่อ

ปริมาณข้อมูลเกินแผนฟรี หรือ cold start ทำให้ webhook ช้าจน LINE ส่งซ้ำเป็นประจำ

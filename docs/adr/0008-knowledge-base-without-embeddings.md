# 0008: คลังความรู้แบบไม่ใช้ embedding

> สถานะ: อนุมัติ · วันที่: 2026-11-18

## บริบท

แผนแรกคือ RAG ด้วย pgvector แต่ Anthropic ไม่มี embedding ของตัวเอง ต้องเพิ่มผู้ให้บริการและ key อีกชุด ขณะที่คลังความรู้ของร้านมีขนาดเล็ก

## การตัดสินใจ

แปลง PDF เป็นข้อความครั้งเดียวด้วย Claude แล้วแนบข้อความทั้งคลังให้โมเดลทุกครั้งที่ตอบ พร้อม prompt caching คลังมีเพดาน 50,000 token แกนกลางขอความรู้ผ่าน port `KnowledgeSource`

## ทางเลือกที่พิจารณา

- RAG ด้วย pgvector กับ Voyage หรือ Bedrock: ต้องมี key เพิ่ม และมีความเสี่ยงค้นไม่เจอกับคำถามสั้น คำเฉพาะ และการแบ่งท่อนภาษาไทย
- ดึงข้อความจาก PDF ด้วยไลบรารี: ภาษาไทยมักได้สระและวรรณยุกต์เพี้ยน และอ่านไฟล์สแกนไม่ได้
- แนบไฟล์ PDF ให้โมเดลทุกครั้ง: ใช้ token มากกว่าการแนบข้อความ

## ผลที่ตามมา

ระบบเหลือ key ของ AI ตัวเดียวและ Postgres ธรรมดา คำตอบแม่นขึ้นสำหรับคลังเล็กเพราะโมเดลเห็นครบ แลกกับต้นทุนต่อข้อความที่ขึ้นตามขนาดคลัง และงานนี้ไม่มี RAG ให้แสดง

## จะทบทวนเมื่อ

คลังความรู้ต้องใหญ่กว่าเพดาน หรือต้นทุนต่อข้อความสูงเกินรับได้ เมื่อนั้นเขียน adapter ของ `KnowledgeSource` แบบค้นด้วยเวกเตอร์

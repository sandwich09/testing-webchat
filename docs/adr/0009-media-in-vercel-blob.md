# 0009: สื่อเก็บใน Vercel Blob และ PDF เก็บเฉพาะข้อความ

> สถานะ: อนุมัติ · วันที่: 2026-11-18

## บริบท

แอดมินต้องส่งรูปและวิดีโอได้ LINE รับสื่อเป็น URL แบบ HTTPS ที่เปิดสาธารณะ และวิดีโอมีขนาดเกินที่ function ของ Vercel รับได้

## การตัดสินใจ

รูปและวิดีโอทั้งขาเข้าและขาออกเก็บใน Vercel Blob โดย browser อัปโหลดตรงด้วยสิทธิ์ที่ server ออกให้ ใน Docker และ CI ใช้ adapter แบบดิสก์ในเครื่อง ส่วน PDF ของคลังความรู้เก็บเฉพาะข้อความที่แปลงแล้วใน Postgres รูปไม่เกิน 10 MB วิดีโอไม่เกิน 50 MB และรับเฉพาะ MP4

## ทางเลือกที่พิจารณา

- เก็บทุกอย่างใน Postgres: ให้ URL สาธารณะไม่ได้ และวิดีโอทำให้พื้นที่เต็มเร็ว
- S3 หรือ R2 กับ MinIO: ทางอัปโหลดเหมือนกันทุกสภาพแวดล้อม แต่ต้องตั้ง bucket, CORS และ key เอง
- แปลงวิดีโอ MOV บน server: ต้องใช้ ffmpeg ซึ่งไม่เหมาะกับ Vercel

## ผลที่ตามมา

ตั้งค่าน้อยที่สุด แต่ทางอัปโหลดของ production กับ Docker ต่างกัน ทางของ Blob จึงต้องทดสอบด้วยมือ และ URL ของสื่อเป็นสาธารณะแบบเดาไม่ได้

## จะทบทวนเมื่อ

ต้องการให้ E2E ครอบทางอัปโหลดของ production หรือโควตาของ Blob ไม่พอ

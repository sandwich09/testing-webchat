# 0006: รหัสเข้าใช้ร่วมกันแทนบัญชีผู้ใช้

> สถานะ: อนุมัติ ข้อการจำกัดการลองรหัส (นับก่อนเทียบรหัส) ถูกแทนที่บางส่วนโดย [0028](0028-review-fixes-concurrency-polling-and-ci.md) · วันที่: 2026-11-18

## บริบท

โจทย์ไม่ได้ขอระบบ login แต่ URL ของ webchat จะถูกส่งให้ผู้ตรวจและอาจอยู่ในที่สาธารณะ ถ้าเปิดโล่ง ใครรู้ URL ก็อ่านแชท ส่งข้อความในนามร้าน แก้ credential และใช้เครดิต AI ได้

## การตัดสินใจ

มีรหัสเข้าใช้หนึ่งตัวใน environment variable หน้ายินดีต้อนรับรับรหัส server ตรวจแล้วออก cookie ที่เซ็นกำกับ อายุ 7 วัน ทุกหน้าและ API ตรวจ cookie ยกเว้น webhook, health และ endpoint ตรวจรหัส และจำกัดการลองรหัสที่ 5 ครั้งต่อนาทีต่อ IP

## ทางเลือกที่พิจารณา

- ไม่มีการป้องกันเลย: ความเสี่ยงข้างต้นทั้งหมดเกิดได้จริง
- บัญชีผู้ใช้เต็มรูปแบบ: เกินขอบเขตของแบบทดสอบ
- ตรวจรหัสเฉพาะในหน้าเว็บ: ข้ามได้ด้วยการเรียก API ตรง

## ผลที่ตามมา

ปิดความเสี่ยงหลักด้วยโค้ดน้อย แต่บอกไม่ได้ว่าใครทำอะไร และรหัสที่ใช้ช่วงทดสอบเดาง่าย จึงต้องพึ่งการจำกัดจำนวนครั้ง

## จะทบทวนเมื่อ

มีผู้ใช้มากกว่าหนึ่งคนที่ต้องแยกสิทธิ์ หรือใช้งานจริงกับลูกค้าจริง

# 0007: Port ของผู้ให้บริการ AI และโมเดลเริ่มต้น

> สถานะ: อนุมัติ ข้อ prompt caching และการสลับโมเดลสำรองถูกแทนที่โดย [0021](0021-explicit-cache-marker-and-fallback-per-model.md) ข้อโมเดลเริ่มต้นถูกแทนที่โดย [0026](0026-neutral-core-prompt-and-layered-settings.md) (`claude-sonnet-5-5`) · วันที่: 2026-11-18

## บริบท

ต้องการให้ AI คุยได้เป็นธรรมชาติ และเผื่อเปลี่ยนผู้ให้บริการในอนาคต

## การตัดสินใจ

แกนกลางเรียก port `ChatModel` ที่เป็นกลาง adapter ตัวแรกใช้ SDK ทางการของ Anthropic โมเดลเริ่มต้นคือ `claude-opus-5-5` และเลือก Sonnet 5.5 หรือ Haiku 5.5 ได้ในหน้าตั้งค่า ใช้ effort `low`, structured output, ไม่ stream, เปิด prompt caching อัตโนมัติ และเปิดการสลับโมเดลสำรองฝั่ง server เมื่อถูกปฏิเสธ รุ่นแรกมี adapter จริงตัวเดียวกับตัวปลอมสำหรับ test

## ทางเลือกที่พิจารณา

- ไลบรารีรวมหลายผู้ให้บริการ: ให้เฉพาะความสามารถที่ทุกเจ้ามีร่วมกัน ขณะที่งานนี้ใช้ prompt caching การอ่าน PDF และรายละเอียด usage
- เรียก SDK ตรงจาก use case: เปลี่ยนเจ้าต้องแก้แกนกลาง
- เขียน adapter ของเจ้าอื่นไว้ล่วงหน้า: ไม่มี key ทดสอบ โค้ดที่ไม่ได้ทดสอบกับของจริงมักใช้ไม่ได้

## ผลที่ตามมา

เปลี่ยนเจ้าได้ด้วย adapter หนึ่งไฟล์ แต่ prompt ต้องทดสอบคุณภาพใหม่ทุกครั้งที่เปลี่ยนโมเดล และโมเดลเริ่มต้นมีราคาสูงกว่ารุ่นเล็ก ซึ่งหน้าค่าใช้จ่ายแสดงให้เห็น

## จะทบทวนเมื่อ

ต้นทุนต่อข้อความสูงเกินรับได้ หรือมีความต้องการใช้ผู้ให้บริการอื่นจริง

# 0018: ใช้ LINE Seed Sans TH จากชุดไฟล์รุ่น 1.003

> สถานะ: อนุมัติ · วันที่: 2026-11-18 · แทนที่ [0017](0017-ibm-plex-until-line-seed-license-verified.md)

## บริบท

[ADR 0017](0017-ibm-plex-until-line-seed-license-verified.md) ให้ใช้ IBM Plex Sans Thai Looped ไปก่อน เพราะยังยืนยันสัญญาอนุญาตของ LINE Seed Sans TH ไม่ได้ ต่อมาเจ้าของงานส่งชุดไฟล์ LINE Seed Sans TH รุ่น 1.003 มาให้ ซึ่งมีโฟลเดอร์ Web, Desktop, App และ Game

ผลการตรวจ metadata ของไฟล์ฟอนต์ในชุดนี้:

- ลิขสิทธิ์: LY Corporation
- ผู้ออกแบบ: Dalton Maag Ltd และตัวอักษรไทยโดย Cadson Demak Co.,Ltd.
- สัญญาอนุญาต: SIL Open Font License รุ่น 1.1
- ชุดไฟล์ไม่มีไฟล์ข้อความสัญญาแยก หลักฐานจึงมาจาก metadata ในตัวฟอนต์

ไฟล์จากแหล่งสำรองที่ตรวจตอนเขียน ADR 0017 เป็นคนละ build และมี metadata ต่างจากชุดนี้

## การตัดสินใจ

ใช้ LINE Seed Sans TH ตามที่ [ADR 0014](0014-ui-stack-and-theme.md) เลือกไว้

- เก็บไฟล์ WOFF2 จากโฟลเดอร์ Web สามน้ำหนักคือ Thin, Regular และ Bold ไว้ที่ `src/common/fonts/line-seed-sans-th/`
- เก็บ `OFL.txt` ไว้ข้างไฟล์ฟอนต์ ประกอบด้วยบรรทัดลิขสิทธิ์และข้อความของ SIL Open Font License 1.1 ตามเงื่อนไขของสัญญาที่ให้แนบประกาศลิขสิทธิ์และสัญญาไปกับฟอนต์
- โหลดแบบ local ไม่พึ่ง CDN
- ไม่ติดตั้งแพ็กเกจฟอนต์ IBM Plex

## ทางเลือกที่พิจารณา

- คง IBM Plex Sans Thai Looped: ไม่ตรงกับภาพตัวอย่างที่อนุมัติ และเหตุผลของ ADR 0017 หมดไปแล้ว
- เก็บทุกน้ำหนักและทุกรูปแบบไฟล์: หน้าจอใช้แค่สามน้ำหนัก และ browser ที่รองรับใช้ WOFF2 ได้ทั้งหมด

## ผลที่ตามมา

หน้าจอจริงตรงกับภาพตัวอย่าง repo มีไฟล์ฟอนต์เพิ่มราว 90 KB ถ้าต้องการน้ำหนักอื่น ให้เพิ่มจากชุดไฟล์เดิมของเจ้าของงาน

## จะทบทวนเมื่อ

LINE เปลี่ยนเงื่อนไขการใช้ฟอนต์ หรือพบว่าชุดไฟล์นี้ไม่ได้มาจากแหล่งทางการ

# 0019: รองรับรูป HEIC ทุก browser ด้วย heic-to

> สถานะ: อนุมัติ · วันที่: 2026-11-18

## บริบท

รูปจาก iPhone มักเป็น HEIC ซึ่ง LINE ไม่รับ ระบบจึงต้องแปลงเป็น JPEG ก่อนส่ง Safari อ่าน HEIC ได้เอง แต่ Chrome และ Firefox อ่านไม่ได้ การแปลงด้วย canvas อย่างเดียวจึงใช้ได้แค่บาง browser เจ้าของงานต้องการให้ใช้ได้ทั้ง Chrome และ Firefox

## การตัดสินใจ

เพิ่ม dependency `heic-to` รุ่น 1.6.7 สำหรับแปลง HEIC และ HEIF เป็น JPEG ใน browser

- โหลดด้วย dynamic import เฉพาะตอนที่แอดมินเลือกไฟล์ HEIC ไม่อยู่ใน bundle แรกของหน้า
- ลองให้ browser อ่านเองก่อน ถ้าอ่านไม่ได้จึงใช้ไลบรารี
- ใช้ build `heic-to/csp` เพื่อไม่ต้องเปิด `unsafe-eval` ในนโยบาย script
- ถ้าแปลงไม่สำเร็จ แจ้งให้ใช้ JPEG หรือ PNG

## ทางเลือกที่พิจารณา

- ไม่เพิ่ม dependency และรองรับ HEIC เฉพาะ browser ที่อ่านได้เอง: เจ้าของงานไม่เลือก เพราะแอดมินส่วนใหญ่ใช้ Chrome
- `heic2any`: สัญญา MIT แต่ไม่มีการอัปเดตตั้งแต่ปี 2023
- แปลงบน server: รูปต้องผ่าน function ซึ่งมีเพดานขนาด request และต้องมีไลบรารีภาพฝั่ง server

## ผลที่ตามมา

- `heic-to` ใช้สัญญา LGPL-3.0 ระบบใช้เป็น dependency ที่ไม่ได้แก้ไขและโหลดแยกเป็นโมดูล ส่วนโค้ดของ repo นี้ยังเป็นสัญญาเดิม ถ้าจะนำระบบไปใช้เชิงพาณิชย์ควรให้ผู้ดูแลด้านกฎหมายตรวจเงื่อนไขนี้
- แพ็กเกจมีขนาดใหญ่ การโหลดเฉพาะเมื่อใช้จึงเป็นข้อบังคับ และการแปลงรูปแรกจะช้ากว่าปกติ
- นโยบาย script ของหน้าเว็บอาจต้องอนุญาต WebAssembly ซึ่งต้องยืนยันตอนสร้าง

## จะทบทวนเมื่อ

Chrome และ Firefox อ่าน HEIC ได้เอง หรือสัญญา LGPL เป็นอุปสรรคต่อการใช้งานจริง

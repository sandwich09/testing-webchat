# 0015: UI ภาษาไทยอย่างเดียว และภาษาของเอกสาร

> สถานะ: อนุมัติ · วันที่: 2026-11-18

## บริบท

ผู้ใช้และผู้ตรวจเป็นคนไทย และระบบสองภาษาเพิ่มงานโดยไม่มีผู้ใช้ภาษาอื่น

## การตัดสินใจ

หน้าจอเป็นภาษาไทยอย่างเดียว ข้อความเก็บเป็นค่าคงที่ในไฟล์ของแต่ละ feature เอกสารเป็นไทยและคงศัพท์เทคนิคเป็นอังกฤษ ส่วนโค้ด, comment, commit, PR, รหัส error และ `AGENTS.md` เป็นอังกฤษ ค่าใช้จ่ายแสดงเป็นดอลลาร์ และ AI ใช้คำลงท้ายที่ร้านเลือก โดยเริ่มต้นที่ "ค่ะ"

## ทางเลือกที่พิจารณา

- ระบบสองภาษา: ไม่มีผู้ใช้ภาษาอื่น
- เอกสารอังกฤษทั้งหมด: ผู้ตรวจอ่านช้ากว่า
- แสดงค่าใช้จ่ายเป็นบาท: ต้องมีอัตราแลกเปลี่ยนที่เปลี่ยนทุกวัน

## ผลที่ตามมา

เขียนเร็วและอ่านง่ายสำหรับผู้ใช้จริง ถ้าจะเพิ่มภาษาภายหลัง ต้องย้ายข้อความเข้าพจนานุกรม

## จะทบทวนเมื่อ

มีผู้ใช้ที่ไม่อ่านภาษาไทย

# 0014: เครื่องมือ UI และ theme

> สถานะ: อนุมัติ · วันที่: 2026-11-18

## บริบท

หน้าจอต้องดูเป็นเครื่องมือแชทที่ใช้จริง สร้างได้เร็ว และภาษาไทยอ่านง่าย

## การตัดสินใจ

ใช้ Tailwind CSS 4, shadcn/ui เฉพาะที่ใช้, lucide และ TanStack Query ไม่มี store กลาง Theme เป็นพื้นสว่าง สีเน้นชมพูบานเย็นกับไล่สีส้มถึงชมพูตามภาพอ้างอิงที่เจ้าของงานเลือก ฟอนต์ LINE Seed Sans TH โครงหน้าเป็นเมนูซ้ายพับได้ รายชื่อ ห้องแชท และแผงข้อมูล ใช้เส้นคั่นแทนการ์ด และมีธีมสว่างอย่างเดียว

## ทางเลือกที่พิจารณา

- ธีมเขียวแบบ LINE: คุ้นตา แต่เจ้าของงานเลือกโทนอื่น
- SWR: เบากว่า แต่ต้องเขียน optimistic update เองมากกว่า
- เขียน component เองทั้งหมด: ช้ากว่า และต้องทำการเข้าถึงด้วยคีย์บอร์ดเอง
- IBM Plex Sans Thai Looped: สัญญาอนุญาตชัดเจน จึงเก็บไว้เป็นตัวสำรอง

## ผลที่ตามมา

สร้างได้เร็วและมีแบบแผนเดียว ข้อที่ต้องระวังคือสัญญาอนุญาตของ LINE Seed Sans TH ต้องตรวจจากแหล่งทางการก่อนใส่ลง repo และตัวอักษรขาวบนส้มอ่านยาก จึงใช้ไล่สีเป็นพื้นหลังเท่านั้น

## จะทบทวนเมื่อ

ต้องการธีมมืด หรือสัญญาอนุญาตของฟอนต์ใช้ใน repo สาธารณะไม่ได้

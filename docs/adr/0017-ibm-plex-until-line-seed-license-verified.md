# 0017: ใช้ IBM Plex Sans Thai Looped จนกว่าจะยืนยันสัญญาอนุญาตของ LINE Seed Sans TH

> สถานะ: ถูกแทนที่โดย [0018](0018-use-line-seed-sans-th.md) · วันที่: 2026-11-18

## บริบท

[ADR 0014](0014-ui-stack-and-theme.md) เลือก LINE Seed Sans TH และกำหนดว่าต้องตรวจสัญญาอนุญาตจากแหล่งทางการก่อนใส่ไฟล์ฟอนต์ลง repo สาธารณะ จากการตรวจเมื่อ 2026-11-18:

- repo ทางการของ LINE Seed บน GitHub มีเฉพาะรุ่นภาษาญี่ปุ่น
- ไฟล์รุ่นภาษาไทยที่หาได้มาจากแหล่งสำรอง และ metadata ในไฟล์ชี้ไปที่สัญญาของบริษัทผู้ออกแบบฟอนต์ ไม่ใช่ OFL
- ไม่มีแพ็กเกจของฟอนต์นี้บน fontsource
- สภาพแวดล้อมพัฒนาเข้าเว็บทางการของ LINE Seed ไม่ได้ จึงอ่านสัญญาที่แนบกับไฟล์ทางการไม่ได้

## การตัดสินใจ

ใช้ IBM Plex Sans Thai Looped ซึ่งเป็น OFL ชัดเจน ติดตั้งจากแพ็กเกจ `@fontsource/ibm-plex-sans-thai-looped` และโหลดแบบ local ชื่อฟอนต์ถูกกำหนดเป็นตัวแปร CSS ตัวเดียว เพื่อให้สลับเป็น LINE Seed Sans TH ได้โดยแก้ที่เดียว

## ทางเลือกที่พิจารณา

- ใส่ไฟล์ LINE Seed Sans TH จากแหล่งสำรองลง repo: เสี่ยงละเมิดสัญญาอนุญาตใน repo สาธารณะ
- โหลดฟอนต์จาก CDN ภายนอกตอนใช้งาน: build ใน Docker และ CI ที่ออกเน็ตไม่ได้จะมีปัญหา และยังไม่แก้เรื่องสัญญา

## ผลที่ตามมา

หน้าจอจริงจะใช้ตัวอักษรแบบมีหัว ต่างจากภาพตัวอย่างที่อนุมัติซึ่งเป็นแบบไม่มีหัว ค่าขนาดและระยะบรรทัดใน [frontend](../architecture/frontend.md) ใช้ได้กับทั้งสองฟอนต์

## จะทบทวนเมื่อ

เจ้าของงานดาวน์โหลด LINE Seed Sans TH จากเว็บทางการและยืนยันว่าสัญญาอนุญาตให้เก็บไฟล์ใน repo สาธารณะได้ เมื่อนั้นเพิ่มไฟล์ฟอนต์พร้อมไฟล์สัญญา และแก้ตัวแปรฟอนต์

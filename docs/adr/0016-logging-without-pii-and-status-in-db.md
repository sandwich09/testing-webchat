# 0016: Log ไม่มีข้อมูลส่วนบุคคล และเก็บสถานะความล้มเหลวในฐานข้อมูล

> สถานะ: อนุมัติ · วันที่: 2026-11-18

## บริบท

ระบบจัดการข้อความของลูกค้า และ log ของ Vercel แผนฟรีเก็บไว้ไม่นาน จึงย้อนดูเหตุการณ์ไม่ได้

## การตัดสินใจ

Log เป็น JSON ผ่าน port `Logger` ที่รับเฉพาะ field ที่อนุญาต ไม่มีเนื้อหาข้อความ ชื่อ รูป เนื้อหา PDF, prompt คำตอบของ AI หรือความลับ ความล้มเหลวที่สำคัญถูกบันทึกในฐานข้อมูลคู่กับสิ่งที่ล้มเหลว และหน้าตั้งค่ามีส่วนสถานะระบบ ไม่ใช้บริการเก็บ error ภายนอก

## ทางเลือกที่พิจารณา

- Sentry หรือบริการคล้ายกัน: เพิ่มบริการและ key และต้องระวังข้อมูลส่วนบุคคลที่ส่งออก
- Log ทุกอย่างเพื่อ debug ง่าย: ข้อมูลลูกค้ารั่วเข้า log

## ผลที่ตามมา

แอดมินเห็นปัญหาได้เองจากหน้าเว็บ แต่ไม่มีการแจ้งเตือนเมื่อระบบขัดข้อง ซึ่งระบุเป็นข้อจำกัด

## จะทบทวนเมื่อ

ใช้งานจริงและต้องมีการแจ้งเตือน

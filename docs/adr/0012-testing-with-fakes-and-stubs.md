# 0012: ทดสอบด้วย adapter ปลอมและ stub โดยไม่ใช้บริการจริงใน CI

> สถานะ: อนุมัติ · วันที่: 2026-11-18 · เสริมโดย [ADR 0032](0032-manual-ai-eval-workflow.md)

## บริบท

LINE และ Claude ของจริงต้องใช้ credential เสียเงิน และให้ผลไม่คงที่ ขณะที่ repo เป็นสาธารณะ

## การตัดสินใจ

มีสี่ชั้น: unit ของแกนกลางด้วย adapter ปลอม, adapter test กับ Postgres และ stub server โดยชุดทดสอบของแต่ละ port รันกับทั้งตัวปลอมและตัวจริง, E2E ด้วย Playwright กับ Docker compose ที่ความกว้าง 1280 และ 390 และสคริปต์ทดสอบด้วยมือกับบริการจริง บังคับ coverage 90% เฉพาะแกนกลาง ชุดคำถามวัดคุณภาพ AI รันเมื่อถูกสั่งเท่านั้น

## ทางเลือกที่พิจารณา

- เรียกบริการจริงใน CI: ต้องเก็บ secret ใน repo สาธารณะและเสียเงินทุกรอบ
- Test ของ component ทีละตัว: logic ถูกแยกเป็นฟังก์ชันล้วนและทดสอบในชั้น unit แล้ว
- เทียบภาพหน้าจออัตโนมัติ: ฟอนต์แสดงผลต่างกันในแต่ละระบบ ให้ผลลวงบ่อย

## ผลที่ตามมา

CI ไม่มี secret และเร็ว แต่ stub ไม่เหมือนของจริงทุกอย่าง จึงต้องรันสคริปต์ทดสอบด้วยมือก่อนส่งงาน

## จะทบทวนเมื่อ

Stub กับของจริงต่างกันจนเกิด bug ที่ test ไม่จับซ้ำ ๆ

# 0021: Cache marker แบบระบุเองตัวเดียว และการสลับโมเดลสำรองตามโมเดล

> สถานะ: อนุมัติ · วันที่: 2026-11-18

## บริบท

[ADR 0007](0007-ai-provider-port-and-default-model.md) ตัดสินให้เปิด prompt caching อัตโนมัติ และเปิดการสลับโมเดลสำรองฝั่ง server เมื่อถูกปฏิเสธ ตอนสร้าง adapter ของ Claude พบสองเรื่อง

- คำขอตอบแชทมีข้อความเวลาปัจจุบันเป็นข้อความสุดท้ายของ `messages` ซึ่งเปลี่ยนทุกนาที breakpoint ของ caching อัตโนมัติ (`cache_control` ระดับบนสุด) จะตกที่ข้อความนี้ จึงมีแต่ค่าเขียน cache โดยไม่ได้อ่านซ้ำ ส่วนที่อ่านซ้ำได้จริงคือคำสั่งระบบกับคลังความรู้
- เป้าหมายสำรองของ Sonnet 5.5 คือ Sonnet 5 ซึ่งไม่รับข้อความระบบกลางบทสนทนา และคำขอที่ใช้การสลับโมเดลสำรองต้องใช้ได้กับทุกโมเดลที่อาจสลับไป เอกสารไม่ได้บอกว่า `fallbacks: "default"` จะปฏิเสธคำขอแบบนี้ตั้งแต่ต้นหรือไม่

## การตัดสินใจ

ข้อนี้แทนเฉพาะสองข้อของ ADR 0007 ข้ออื่นของ ADR 0007 คงเดิม

- คำขอตอบแชทมี `cache_control: { type: "ephemeral" }` แบบระบุเองตัวเดียวที่บล็อกคลังความรู้ (`system[1]`) และไม่ส่ง `cache_control` ระดับบนสุด
- การสลับโมเดลสำรองฝั่ง server ใช้กับ Opus 5.5 ทั้งการตอบแชทและการแปลง PDF และกับ Sonnet 5.5 เฉพาะการแปลง PDF (ไม่มีข้อความระบบ) การตอบแชทของ Sonnet 5.5 ไม่ใช้ และ Haiku 5.5 ไม่ใช้เลย เมื่อโมเดลที่ไม่ใช้การสลับปฏิเสธ แชทขึ้นรอแอดมิน การตัดสินอยู่ที่ `usesServerFallback` ใน `src/adapters/claude/claude.mapper.ts` ที่เดียว
- เมื่อใช้การสลับโมเดลสำรอง token ที่บันทึกเป็นผลรวมของ `usage.iterations` และโมเดลที่คิดราคาคือ `model` ของข้อความสุดท้าย

รายละเอียดอยู่ใน [ai-prompt ข้อ 3](../specs/ai-prompt.md#3-โครงของ-request) และ [usage-cost](../specs/usage-cost.md)

## ทางเลือกที่พิจารณา

- ใช้ caching อัตโนมัติร่วมกับ marker ที่ `system[1]`: จ่ายค่าเขียน cache ของส่วนท้ายทุกครั้งโดยไม่ได้อ่านซ้ำ
- ใส่เวลาปัจจุบันใน `system` แทน: cache ของคำสั่งระบบและคลังความรู้ใช้ไม่ได้ทุกนาที
- เปิดการสลับโมเดลสำรองให้การตอบแชทของ Sonnet 5.5: เสี่ยงได้ 400 ทุกครั้งที่ตอบ

## ผลที่ตามมา

- ส่วนที่ cache คือคำสั่งระบบกับคลังความรู้ ประวัติแชทไม่ถูก cache ซึ่งอ่านซ้ำได้น้อยอยู่แล้วเพราะเลื่อนทีละข้อความ
- การตอบแชทของ Sonnet 5.5 ที่ถูกปฏิเสธส่งต่อให้แอดมินแทนการสลับไปโมเดลอื่น เหมือน Haiku 5.5

## จะทบทวนเมื่อ

เอกสารของ API ยืนยันว่าคำขอที่มีข้อความระบบกลางบทสนทนาใช้กับการสลับโมเดลสำรองของ Sonnet 5.5 ได้ หรือเป้าหมายสำรองของ Sonnet 5.5 เปลี่ยน
